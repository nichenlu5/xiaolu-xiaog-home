# xiaolu-xiaog-home

这里是“小路 × 小G”一起长期建设的小家。它不只是一次性小游戏项目，也会随着我们继续学习、生活和创造，一点点扩展出新的房间与回忆。

🌐 在线访问：[https://nichenlu5.github.io/xiaolu-xiaog-home/](https://nichenlu5.github.io/xiaolu-xiaog-home/)

## 已经实现

### 🧠 知识擂台

从不同知识类别中随机抽题，可选择简单、普通、困难或随机难度。支持单人 10 题挑战、“小路 VS 小G”面对面双人答题，以及根据浏览器错题记录进行复习的“错题复仇”；同时会保留错题本与近期双人战绩。

### 🎵 猜歌词

每局随机进行 5 题，根据歌词、关键词或歌曲线索，从四个选项中猜出歌名。小路先选择并隐藏答案，再手动录入小G的答案，最后一起揭晓。当前题库可选“经典”“流行”或“随机”。

### ⏱️ 读秒挑战

单人时间感挑战，共 3 回合。可选择 5、10 或 15 秒作为目标；开始后计时数字隐藏，在感觉时间到了时停止，系统会显示实际用时与误差，并记录浏览器中的最佳成绩。

### 💞 默契挑战

每局随机抽取 10 道偏好与生活选择题。小路先作答并藏好答案，再手动录入小G的选择；两人答案相同即可积累默契分，还可以查看历史最高分和最近十局趋势。

### 🃏 记忆翻牌

依次翻开两张牌寻找相同图案，支持 12、16、20 张三档难度。单人模式挑战更短用时与更少步数；双人模式中，配对成功可以继续翻牌，失败则交换回合，最终按配对数决出结果。

### 🌍 世界猜猜猜

可选择“猜国家”或“猜城市”，每局 10 题。每题最多逐层查看 4 条线索，越早猜中得分越高；答错会自动解锁下一条线索，并记录积分、连续猜对与历史最佳。

### 🗺️ 猜省份

看到城市名称后，在省级行政区列表中选出它所属的省份。支持 10 题和 20 题挑战，并统计得分、连续答对、最高连胜与历史最佳。

### 📚 文学挑战

包含四大名著随机问答、需要输入上下句的诗词接龙，以及可取消和重新配对的作者作品左右匹配。

### 🥧 背圆周率

从 `π = 3.` 后连续输入数字，按第一次错误位置计算成绩。支持自由背诵和 60 秒挑战，并分别保存历史最高位数。

### 🔎 线索猜猜猜

人物、地点、事物和混合四种分类，每题逐步解锁 4 条线索并开放输入答案，支持常见别名，按使用线索数获得 4 / 3 / 2 / 1 分。

### ⚡ 限时快答

经过 3 / 2 / 1 / GO 倒数后连续挑战 20 道常识题，每题限时 10 秒，包含自动切题、超时、连击、速度加分和完整战绩统计。

### 🏆 全局成就墙

汇总各个游戏在当前浏览器里的游玩记录与里程碑，集中展示已经解锁和仍待解锁的成就，让一起玩过的每一局都有迹可循。

### 🌱 一起想做的事

保存两个人想一起做的事情，并在“想做 → 在做 → 已完成”之间更新进度。旧版网站积累的 450 条真实愿望已经融入当前页面，并完整保留 21 个主题和 4 档实现门槛；支持收藏、搜索、组合筛选、随机抽取、新增、编辑、确认删除、完成日期与本地保存。

## 技术栈

HTML / CSS / Vanilla JavaScript / localStorage / GitHub Pages

项目无需构建工具，直接用浏览器打开 `index.html` 即可本地浏览；也可以通过任意静态文件服务器运行。

## 数据说明

当前游戏记录与“一起想做的事”主要保存在浏览器的 `localStorage` 中，不会上传到服务器，因此不同浏览器、不同设备之间暂时不会自动同步。清除浏览器站点数据也可能同时清除这些记录。
